THE GRID — PRIVATE V4+ UNIVERSAL
=================================

This is ONE responsive website, not separate desktop and mobile builds.

It keeps the full private v4+ desktop design and automatically adapts for:
- desktop browsers
- laptops
- tablets
- iPhone
- Android phones

MOBILE / TABLET IMPROVEMENTS
----------------------------
- iPhone notch / Dynamic Island safe-area support
- Android and iOS touch-friendly controls
- single-column mobile layouts where appropriate
- responsive driver profile layout
- responsive team/archive cards
- mobile-safe top menu
- improved comparison screens on narrow displays
- touch feedback instead of relying on hover
- diagonal arrow forced to text rendering so iOS does not swap it for an emoji-style icon
- viewport-fit=cover support
- reduced accidental zoom/callout behavior on controls

DESKTOP
-------
The desktop layout and visual system remain the private v4+ design.

DEPLOYMENT
----------
Upload this single project anywhere you host the private site.
There is no separate mobile URL or mobile folder.
